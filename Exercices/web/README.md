# Mini projet HTML/CSS débutant

## Structure
- `index.html`
- `css/style.css`
- `images/banner.svg`
- `pages/apropos.html`
- `pages/contact.html`

## Pour lancer le projet
1. Ouvre le dossier
2. Double-clique sur `index.html`
3. Navigue entre les pages avec la barre de navigation

## Objectif pédagogique
Ce mini projet montre :
- une barre de navigation
- une sidebar
- une zone principale
- un footer
- une organisation propre des fichiers
